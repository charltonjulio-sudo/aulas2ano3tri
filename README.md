# Site Aula Viva — 2º ADM (Informática Empresarial)

Aulas 29, 30 e 31, feitas com o Kit Aula Viva 1.1.0.

## Publicar
1. Crie um repositório no GitHub (sugestão: `aula-viva-2adm`) e suba **todo o conteúdo desta pasta**. Se preferir, pode ser uma subpasta de um repositório que já existe.
2. Settings → Pages → Branch `main`, pasta `/ (root)` → Save.
3. Link dos alunos: `https://charltonjulio-sudo.github.io/<repositório>/`. Painel do professor: o mesmo link com `?professor` no final.

## Aula do dia
O arquivo `aulas.js` mostra só a aula do dia (hoje está a 29). Para trocar, mude a linha `pasta:` para:
- `aulas/a30-recursos-multimidia/`
- `aulas/a31-drive-docs-planilhas-slides/`
